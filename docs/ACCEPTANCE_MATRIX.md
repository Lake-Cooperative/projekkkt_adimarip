# Контрольные критерии завершения (этапы M2–M9)

| Сценарий | Ожидание |
|---|---|
| GET /api/health без JWT | 200, `status=ok` |
| GET /api/notices без JWT | 401 |
| Вход с верным паролем | 200, JWT и роль |
| Вход с неверным паролем | 401 |
| Engineer обращается к `/api/notices` | 403 |
| Observer создаёт оповещение | 403 |
| Observer читает своё оповещение | 200, без истории/аудита |
| Observer запрашивает чужое оповещение | 404 |
| Manager открывает карточку | 200, включая аудит |
| Operator открывает карточку | 200, включая историю, без аудита |
| POST /api/notices с пустой причиной | 400 |
| POST /api/notices с повторным номером | 409 |
| PATCH status на текущее или недопустимое значение | 409 |
| Правильный переход статуса | Новая история и аудит |
| Канал уведомления вне разрешённого списка | 400 |
| Демонстрационная отправка | Запись с `simulated=true`, внешней отправки нет |
| Обращение с пустым текстом | 400 |
| POST /api/notices/{id}/documents с http/js URL | 400 |
| Списание адресата | Скрыт из справочника, история сохранена |
| Создание оповещения списанному адресату | 409 |
| Engineer создаёт учётную запись | 201, пароль хеширован |
| Имя логина уже есть | 409 |
| Фильтрация/пагинация | `items`, `total`, `page`, `pageSize`, `totalPages` |
| Применение SQL-миграций | Полный набор таблиц и индексов |

Важно: проверяйте эти сценарии в запущенном Docker и не используйте реальные сведения о гражданах.
