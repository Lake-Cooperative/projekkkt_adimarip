# Передача на сборку и приёмку

## Команды проверки

```bash
# Из корня настоящего клона исходного GitHub-проекта после применения всех патчей
docker compose -f docker_compose.yml config
docker compose -f docker_compose.yml up -d --build
docker compose -f docker_compose.yml ps
curl -i http://localhost:8081/api/health
python3 tests/api_acceptance.py
# SQL-проверка (только чтение):
docker compose -f docker_compose.yml exec -T db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < tests/sql/schema-verification.sql
```

## Контроль корректности

1. Проверить наличие 12 таблиц предметной модели и `AppUsers`.
2. Проверить применённые миграции в `__EFMigrationsHistory`.
3. Проверить ролевые запреты API (401/403), особенно доступ Observer к чужим оповещениям.
4. Проверить атомарность истории и аудита при создании и смене статуса.
5. Проверить, что архивный адресат больше не предлагается для создания нового оповещения.
6. Проверить UI через роли и узкий экран браузера.
7. Создать по одному примеру уведомления, обращения, документа; показать результаты в карточке.
8. Согласовать фактические требования ТЗ: в этой учебной версии нет настоящих поставщиков доставки, Госуслуг или MAX-авторизации.

**Проверено при подготовке ZIP:** оригинальные Git blob SHA файлов, затронутых patch-серией, совпали с удалённым GitHub; TypeScript/TSX прошли проверку синтаксического парсинга; Python smoke-test прошёл `py_compile`; последовательность коммитов локально создана. **Не проверено:** сборка C# и Docker, реальные HTTP-вызовы к поднятому сервису.
