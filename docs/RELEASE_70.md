## Совместимость

* Маршруты и формат ответов прежние. Новые поля: `permissions`, `roleDisplayName` во входе; `allowedTransitions`,
  `canAcknowledge`, `broadcastId`, `severity` в карточке; `status`, `lastError` у уведомлений.
* Пароли и учётные записи сохраняются (формат хеша не изменился).
* Миграция `202611190006_RolesAndBroadcasts` применяется автоматически при старте API: создаёт `Roles`, `RolePermissions`,
  `Broadcasts`, добавляет `Notices.BroadcastId`, `Notifications.Status/LastError`, `Recipients.OfficeId`; уже записанные
  уведомления получают статус `Delivered`. Перед применением на важном томе сделайте `scripts/backup-db.sh`.
* Каналы SMS/MAX теперь проверяют формат номера, e-mail — формат адреса: неверный адрес даёт уведомление со статусом `Failed`
  и текстом ошибки (раньше любая строка считалась доставленной). Тестовый адрес в формах подставляется по каналу.
* Инженер автоматизации теперь видит справочник подразделений (нужно для привязки работника к подразделению).
* Неизвестный статус в `PATCH /api/notices/{id}/status` — `400` вместо `409`; значения перечислений с числами отклоняются.

## Как показать на защите (демо-режим)

Пароль всех учётных записей — значение `DEMO_PASSWORD` (по умолчанию `demo-password-change-me`).

1. `docker compose -f docker_compose.yml up --build`, открыть http://localhost:8080.
2. **Кастомная роль.** Войти `engineer` → «Роли и права» → «Копировать» у «Секретаря» или «+ Новая роль», отметить права.
   В «Учётных записях» создать пользователя с этой ролью. Изменить права роли — сервер применяет их сразу, без повторного входа (меню у пользователя обновится после перезагрузки страницы).
3. **Массовое оповещение.** Войти `manager` (или `duty` — пример кастомной роли «Дежурный по безопасности») → «Массовое оповещение»:
   важность «Срочно», аудитория «Все действующие работники» → «⚠ Оповестить срочно». Через 1–2 секунды отчёт покажет доставку:
   у работника без контактов сработает портал, у адреса `fail-mailbox@…` — ошибка в списке недоставленных.
4. **Подтверждение.** Войти `observer` → красный баннер срочного оповещения → «Ознакомлен(а)». В отчёте рассылки растёт «подтвердили получение».
5. Повторы временных сбоев можно показать, запустив стек с `DELIVERY_FAILURE_RATE=0.3`.

## Ограничения

Доставка только имитируется; массовое оповещение работает лишь при `DEMO_ENABLED=true` (иначе `501`, как и прежние уведомления);
до 2000 адресатов за рассылку; очередь — в памяти одного процесса (рассылки восстанавливаются из БД при перезапуске,
но несколько экземпляров API одновременно обрабатывать очередь не должны).
