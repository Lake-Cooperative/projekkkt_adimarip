# ROADMAP
## Проект «Реестр оповещений „АДИМАРИП“»

**Состояние на 20.10.2026.** Реализованы этапы M1–M9: вход и роли, справочники, ядро реестра, статусы с историей и аудитом, демонстрационные уведомления (в том числе массовые), обращения, метаданные документов, интерфейс для всех ролей, автотесты и CI. Добавлен этап M10 (эксплуатация). 

Дорожная карта по [`business_requirements.md`](business_requirements.md) и [`system_requirements.md`](system_requirements.md).

## Ожидают проверки

Эти доработки написаны, но не прогонялись в .NET и CI — перед защитой выполнить `dotnet build`, `npm run build`, `docker compose up --build`, `python3 tests/api_acceptance.py`:
служащий = адресат (создание в одной транзакции), создание адресатов только инженером, фамилия и ID в шапке, вход без учёта регистра, ограничение даты создания оповещения.
