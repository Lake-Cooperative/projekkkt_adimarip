# Реестр оповещений «АДИМАРИП»

Учебный командный проект кооператива «Озеро». **Семинар 2 находится в разработке.**

## Что уже есть

- Входной репозиторий содержал требования, Use Cases, ERD и EF Core-модель данных.
- Добавлен минимальный ASP.NET Core 8 API: `GET /api/health` и Swagger в Development.
- Начат React 18 / TypeScript / Vite frontend со стартовой страницей и индикатором доступности API.
- CRUD, JWT, работа со статусами и реальная отправка уведомлений пока отсутствуют.

## Что осталось до окончания этапа

- Интеграция EF Core с сервисом API и документация запуска.
- Docker-контейнеры и рабочий Compose-файл.
- Проверка браузерного доступа к API и smoke-тест.

План: [docs/ROADMAP.md](docs/ROADMAP.md). Модель данных: [docs/erd.md](docs/erd.md).
