## Важные условия

- Запуск: `docker compose -f docker_compose.yml up --build`.
- UI: `http://localhost:8080`; API: `http://localhost:8081`; Swagger: `http://localhost:8081/swagger`.
- Учебные учётные записи (`DEMO_ENABLED=true`): `operator`, `manager`, `observer`, `engineer`.
- Пароли не должны использоваться в реальном окружении; настройте `.env`.
- Все имена адресатов и оповещения — вымышленные; внешняя доставка только имитируется.
- Не используйте систему для реальных оповещений: качество сборки и интеграции
  должно быть проверено командой. В исходном окружении отсутствовали .NET SDK и Docker.

Исходная документация и роли сохранены; существующая история Git не переписывается.
